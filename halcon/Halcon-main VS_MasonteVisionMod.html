1. 系统启动与初始化逻辑 (System Startup & Initialization)

核心逻辑说明：
  • 进程清理与唯一性检查：启动时先查找并关闭 VisionMaster 进程，通过 Mutex 确保 MasonteVision 应用程序只有一个实例在运行。
  • 资源申请：调用 DllFunction.WF_InitRes 申请 4K 相机内存空间（支持4路并发）。
  • 相机连接：通过 IpToInt 转换 IP 地址，结合端口号初始化 4 台相机，并获取曝光、增益等核心底层参数。
  • UI 绑定：动态创建 4 个 HaGUI 控件并嵌入 tableLayoutPanel，将相机视频流句柄定向至对应的 PictureBox。

2. 核心分析触发逻辑 (Core Trigger & Analysis Flow)

核心逻辑说明：
  • 状态检查：在触发测试前，必须确保相机处于非忙碌状态 (IsCamBusing == false) 且视觉参数已完全加载。
  • 图像采集：通过 SaveImage 方法捕获相机当前帧，按照 Code/Dut/Dot 层级结构存入指定路径。
  • 算法运行：利用 HaGUILoadImage 将图片载入内存并在界面展示，随后异步调用 my2DhalconFlow.RunHalconFlow。
  • 结果输出：从工具链获取 ToolResult 和 RunResult，判定结果并同步写入系统日志。

3. 背景监控与超时处理逻辑 (Monitoring & Timeout Logic)

核心逻辑说明：
  • 独立线程：系统维护 RunningThread[3] 专门用于心跳监测与超时处理，不阻塞主分析流。
  • 双重监测机制：
    • 取图超时：若 IsCamBusing 为真且 5 秒内未获取到图像帧，视为相机取图异常。
    • 分析超时：若取图成功但算法处理时间超过 5 秒未返回 IsCamRunFinished，判定为算法挂起。
  • 安全保护：一旦触发超时，系统强制重置 Busy 标志位，上报错误消息，防止上位机 PLC 进入无限等待。

4. 3D 标定与坐标转换逻辑 (AffineMat3D Logic)

核心逻辑说明：
  • 矩阵建立：通过多组已知的 X, Y 坐标及对应的激光传感器 Z 高度，利用 Halcon 的 VectorToHomMat3d 建立 3D 空间映射模型。
  • 坐标预测：RunVision 方法实现了"相机引导"功能，输入平面坐标 (X, Y)，输出激光头需要移动到的预测高度 (Z)。
  • 持久化：利用 Serialize 技术将复杂的 3D 变换矩阵转换为 .mat 二进制文件，支持不同机种参数的快速调取与读取。

public class AffineMat3D { HTuple Px, Py, Pz, Qx, Qy, Qz, HomMate3DModel, Height; HTuple SerializedItemHandle, FileHandle; /// /// 输入坐标 /// /// 输入X /// 输入Y /// 输入激光传感器高度Z /// 输入设定的相机高度 public AffineMat3D(double[] InPutx, double[] InPuty, double[] InPutz, double ConstHeight) { Qx = InPutx; Qy = InPuty; Qz = InPutz; Height = ConstHeight; Px = Qx; Py = Qy; HOperatorSet.TupleGenConst(Qz.Length, Height, out Pz); } /// /// 求高度 /// /// 输入X /// 输入Y /// 得到激光传感器需要到达的高度 public void RunVision(double X, double Y, out double Z) { HTuple NeedX, NeedY, NeedHeight; HOperatorSet.AffineTransPoint3d(HomMate3DModel, X, Y, Height, out NeedX, out NeedY, out NeedHeight); Z = NeedHeight; } /// /// 建立3D矩阵 /// public void Create3dModel() { HOperatorSet.HomMat3dIdentity(out HomMate3DModel); HOperatorSet.VectorToHomMat3d("similarity", Px, Py, Pz, Qx, Qy, Qz, out HomMate3DModel); } /// /// 保存矩阵 /// /// public void SaveModel(string SavePath) { HOperatorSet.SerializeHomMat3d(HomMate3DModel, out SerializedItemHandle); HOperatorSet.OpenFile(SavePath + "HomMat3D.mat", "output_binary", out FileHandle); HOperatorSet.FwriteSerializedItem(FileHandle, SerializedItemHandle); HOperatorSet.CloseFile(FileHandle); } /// /// 读取矩阵 /// /// public void ReadModel(string LoadPath) { HOperatorSet.OpenFile(LoadPath + "HomMat3D.mat", "output_binary", out FileHandle); HOperatorSet.FreadSerializedItem(FileHandle, out SerializedItemHandle); HOperatorSet.DeserializeHomMat3d(SerializedItemHandle, out HomMate3DModel); HOperatorSet.CloseFile(FileHandle); } }
