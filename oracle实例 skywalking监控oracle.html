Oracle 实例 (Instance) 与 数据库 (Database) 逻辑全景

核心逻辑： Oracle 采用“内存实例+物理存储”分离架构。 1. Instance 是动态的（内存+进程），重启即消失； 2. Database 是静态的（磁盘文件），永久存储。

Schema 与 User 的对应逻辑

逻辑说明： 在 Oracle 中，用户 (User) 与 模式 (Schema) 是一对一关系。Schema 是一个逻辑容器，存储表、索引、视图等。
