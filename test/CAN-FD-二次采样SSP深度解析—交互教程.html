CAN FD 二次采样（SSP）怎么搞定发送延迟？

数据相位能跑到 2~5 Mbps，位宽比收发器自己的环路延迟还短。发送节点怎么监听自己发出的位、判断有没有发错？

核心结论
不改物理线路，改"裁判时机"——TDC（发送延迟补偿）先等回声回来，SSP（二次采样点）再往里挪一点到最稳位置比对。靠改变采样时刻，让数据相位突破收发器环路延迟的限制。

反直觉疑惑

CAN FD 数据相位能跑到 2~5 Mbps，位宽比收发器自己的环路延迟还短。那发送节点怎么监听自己发出的位、判断有没有发错？难道不会"自己骗自己"？

经典 CAN 的限制

采样点固定在 75%~87% 处。如果发送延迟 > TSEG1，SP 时刻采样 RX 看到的还是旧电平 → 误报位错误。所以经典 CAN 最高只能 1 Mbps。

CAN FD 的解法

仲裁段慢（≤1Mbps）、数据段快（2~5Mbps）。数据段用 TDC+SSP，把"裁判哨子"往后吹，等回声真正回来了再判。

山谷喊话与回声 — TDC 的拟物类比

想象你在山谷里对着岩壁喊话测试距离。没有 TDC 是"喊完立刻听"，有 TDC 是"等回声回来再听"。

类比对应：喊话 = TX 发位；岩壁 = CAN 收发器环路；回声 = RX 收到的信号；立刻听 = 常规采样点 SP；等回声再听 = 二次采样点 SSP；TDC = "先等一会儿"的延迟补偿。

为什么仲裁相位不用 TDC？

  • 速度慢：仲裁相位 ≤ 1 Mbps，位宽 1000ns+，远大于环路延迟（~150ns），延迟不是问题
  • 需要统一采样点：仲裁是多个节点同时竞争总线，所有节点必须在同一时刻采样才能公平比较 ID。TDC 让每个节点的 SSP 位置不同，会破坏仲裁公平性
  • 协议规定：ISO 11898-1 明确要求仲裁相位禁用 TDC
结论：TDC 只在数据相位生效——这时候只有一个节点在说话，不存在公平性问题，可以放心按自己的节奏"晚判"。

信号跑一圈要时间 — 环路延迟根源

发送节点的 TX 发出信号，经过收发器驱动到总线、再被同一颗收发器接收、回到 RX——这一圈闭环就是环路延迟。

工程建议：DTSEG1、TDCO、TDCF 三个值设成一样大（单位都是 mtq）。这是 TI 和 Bosch 文档的通用推荐配置——把 SSP 放到位时间约 80% 处，最稳定。

TDCF 滤波窗口：防"假回声"

实际车载环境电磁干扰强，RX 引脚上可能出现短暂的显性毛刺（Glitch）。如果没有保护，这个毛刺可能被误认为是 FDF 边沿的回声，导致测量过早结束 → 延迟偏小 → SSP 提前 → 又误判了。

TDCF 定义了 SSP 位置的最小值门槛：任何会导致 SSP 小于 TDCF 的早期边沿都会被忽略，确保测量不会被噪声欺骗。

延迟怎么测？——每帧自动量一次

TDC 最精妙的地方：不需要工程师手动测量延迟，硬件自己量。每发一帧 CAN FD 报文就更新一次。

测量窗口官方定义：从 FDF 位（隐性=1）到 res 位（固定显性=0）的下降沿开始，到该边沿被 RX 收到为止。不要去量 BRS 位——那是波特率切换，不是 TDC 测量窗口。

存在哪里？

测量结果以 mtq（最小时间量子）为单位存储在寄存器 PSR.TDCV 中：

  • 1 mtq = CAN 控制器的时钟周期（40 MHz → 25ns；80 MHz → 12.5ns）
  • 每发送一帧 CAN FD 报文就更新一次（实时跟踪温度/电压变化导致的延迟漂移）
  • 当控制器进入初始化模式（CCCR.INIT=1）时清零

二次采样怎么测？——四种工程方法

按"基准 → 实时 → 功能 → 定位"四步走，每一步都明确用什么工具、预期看到什么。

1

示波器法：量环路延迟

数字示波器 ≥200MHz + 双通道探头

CH1 → CAN_TX，CH2 → CAN_RX，共地。发一帧 CAN FD，边沿触发捉 FDF→res 下降沿，光标量 TX 到 RX 的时间差 Δt。

预期：Δt 在 60~250ns（TJA1042 规格内）；Δt ÷ mtq ≈ PSR.TDCV，误差 ≤ 1 mtq
2

寄存器观测法：看 TDCV

J-Link / DAP / XCP on CAN

读 MCAN PSR[22:16]（TDCV 字段），连发若干帧 CAN FD，每帧后读一次。

预期：数值每帧变化（非固定初值）；典型几到几十 mtq，必须 < 127；换收发器/调电压/升降温后数值漂移
3

功能对比法：开关 TDC

CANoe + VN 系列接口卡 / 错误计数器

5 Mbps 数据相位，分别设 DBTP.TDC=0 和 =1，各发一批帧，对比错误帧和 TEC。

预期：开 TDC → 通信正常，TEC 不涨；关 TDC → 大量 Bit Error，错误帧爆发，TEC 飙升。B 出错误、A 消失 = SSP 生效铁证
4

干扰仪扫描法：定 SSP 位置

VH6501 CAN 干扰仪 + CANoe

在数据段某个位的位时间内注入纳秒级显性干扰，扫描干扰起始位置（50%~90%），观察 DUT 是否报位错误。

预期：最后一个能触发位错误的干扰位置 = 实测 SSP；应落在 60%~80% 位时间，避开振铃区

一句话记住测试流程

四步验证法
示波器量基准（Δt≈TDCV×mtq）、寄存器看实时（每帧更新<127）、开关 TDC 验功能（关则爆错误帧）、干扰仪定位置（SSP≈60~80%位时间）——四步把"二次采样"从原理变成可验证的工程事实。

边界与鲁棒性测试

  • TDCO/TDCF 扫描：固定 TDCV 扫 TDCO，看 SSP = TDCV+TDCO 是否按公式变化；调到使 SSP 超过 127mtq → 验证硬件截断
  • TDCF 防毛刺：用 VH6501 在 RX 上注入短显性毛刺，验证 TDCF 滤波窗口能否挡住
  • 收发器/温度/电压扫描：不同收发器（TJA1042/TCAN1042）、不同温度、不同供电下重复测试，确认 TDC 自动补偿覆盖漂移

知识小结

核心要点速查表，一页回顾全部知识点。

问题根源

CAN FD 数据相位 2~5Mbps，位宽（200ns@5Mbps）比收发器环路延迟（~150ns）还短，常规采样点会误判位错误。

TDC 核心思想

不改物理，改"裁判时机"——等回声真正回来了再判。TDC = 先等一会儿，SSP = 等完再做判断。

延迟自动测量

每帧 FDF 位下降沿启动，RX 回声停止，结果存 PSR.TDCV（mtq），每帧更新，跟踪温漂。

SSP 位置公式

SSP = TDCV（实测延迟）+ TDCO（偏移量）。推荐 DTSEG1 = TDCO = TDCF，SSP 落在约 80% 位时间。

TDCF 作用

SSP 位置最小值门槛，防止 RX 显性毛刺被误认为回声，导致测量过早结束。

仲裁不用 TDC

仲裁段 ≤1Mbps 延迟不是问题；多节点竞争需要统一采样点；协议明确要求仲裁相位禁用 TDC。

关键寄存器

DBTP[23]=TDC使能；TDCR[14:8]=TDCO；TDCR[6:0]=TDCF；PSR[22:16]=TDCV（只读）。

边界条件

SSP ≤ 127 mtq（超过截断）；SSP < 6 个数据位时间。接近 127 说明补偿可能失效。

测试四步法

示波器量基准、寄存器看实时、开关TDC验功能、干扰仪定位置。

一句话记住
经典 CAN 像"喊完立刻听"——慢的时候没问题，一快了回声还没回来就误判。CAN FD 的 TDC + SSP 像"喊完等回声回来再听，还多等一小会儿确保听得清"——靠改变裁判时机而不是改物理线路，让数据相位突破收发器环路延迟的限制，稳稳跑到 2~5 Mbps 甚至更高。
