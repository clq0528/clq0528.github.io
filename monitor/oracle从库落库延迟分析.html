Redo Log 与 Alert Log 的本质区别

纠正误区： 备库同步的数据源是二进制的 Redo Log，而 Alert Log 只是文本说明书。 

包含：RowID, 改变前后的值, SCN...
作用：真正落库到备库表里的数据。
 

包含：MRP启动/停止时间, ORA错误代码...
作用：用来查为什么 10:30 同步停了。

为什么 11:00 又能查出来了？

推测逻辑： MRP 进程在 10:30 处于 IDLE（可能是因为报错停止或人为关闭），但在 11:00 前被重新拉起或执行了手动同步。 
-- 1. 查看 MRP 进程当前在做什么？
SELECT process, status, sequence# FROM v$managed_standby_db;

-- 2. 查看是否有延迟参数设置？
SELECT dest_id, delay_mins FROM v$archive_dest WHERE target='STANDBY';

-- 3. 实时开启同步命令（治本方案）
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE USING CURRENT LOGFILE DISCONNECT;
