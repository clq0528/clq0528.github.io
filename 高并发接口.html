系统业务逻辑

1. 发送方连接池 (RestTemplate)

基于 Apache HttpClient。关键参数：

MaxTotal: 200 (全局总连接)
MaxPerRoute: 100 (单目标最大连接)

若请求产生频率高于后端处理速度，此处的矩阵节点将全部变亮，新请求将进入阻塞等待状态。

2. 接收方 Nginx 负载均衡

作为反向代理，负责请求的初步接收与转发。Nginx 是非阻塞 IO，吞吐量极大。但如果后端 Tomcat 响应过慢，Nginx 会消耗掉所有可用的 `worker_connections`。

3. 后端线程矩阵 (Tomcat/Spring)

Tomcat 默认 `maxThreads=200`。每一个小球代表一个正在运行的线程任务。如果此处满载，Tomcat 无法接收新请求，客户端将感受到明显的延迟。

4. 数据库连接池 (HikariCP)

这是整条链路最窄的瓶颈点（通常设为 10-30）。如果 SQL 语句没有索引或者存在死锁，会导致大量后端线程卡在 DB 调用阶段无法释放。
