Halcon 机器视觉全流程算子与逻辑架构

基于 HObject 数据体系的图像处理、几何变换与特征分析指南

1. 基础数据结构 (Data Types)

Halcon 将所有视觉数据封装为 HObject。Image 提供像素矩阵，Region 提供坐标集合实现高效 ROI 操作，XLD 提供亚像素精度的矢量轮廓，Tuple 则负责非图形化的参数运算。
graph LR HObject --> Image[Image: 像素矩阵/通道] HObject --> Region[Region: 坐标压缩集合/离散点] HObject --> XLD[XLD: 亚像素轮廓/多边形] Tuple[Tuple: 数组/句柄/数值控制] style HObject fill:#1890ff,stroke:#003a8c,color:#fff style Tuple fill:#f5222d,stroke:#a8071a,color:#fff

2. 几何变换与九点标定 (Transformations)

逻辑：通过创建单位矩阵，级联平移、旋转、缩放参数，最后将其应用到目标对象。九点标定本质上是寻找像素坐标系与物理坐标系之间的单应性矩阵映射。
graph LR Init[hom_mat2d_identity] --> Set[平移/旋转/缩放算子] Set --> Apply{affine_trans_*} Apply --> |图像| TransImg[affine_trans_image] Apply --> |区域| TransReg[affine_trans_region] Apply --> |轮廓| TransXLD[affine_trans_contour_xld] Points[像素/机械坐标对] --> Calib[vector_to_hom_mat2d] Calib --> Matrix[生成仿射矩阵] Matrix --> Decompose[hom_mat2d_to_affine_par]

3. ROI 裁剪与图像增强 (Preprocessing)

逻辑：Halcon 的 ROI (reduce_domain) 不会生成新图像，而是建立一个掩膜范围。后续算子仅在范围内运算，极大提升效率。增强侧重于频率域或空域的对比度拉伸与噪声抑制。
graph LR Raw[原始图像] --> GenROI[gen_rectangle/circle] GenROI --> Reduce[reduce_domain] Reduce --> Filter{滤波/增强} Filter --> Mean[mean_image: 均值去噪] Filter --> Gauss[gauss_filter: 高斯平滑] Filter --> Shock[shock_filter: 边缘锐化] Filter --> Equ[equ_histo_image: 直方图均衡]

4. 图像分割 (Segmentation)

逻辑：根据灰度特征将目标从背景分离。全局阈值适合光照均匀场景；动态阈值 (dyn_threshold) 适合背景复杂或打光不均；区域生长适合处理具有相似纹理的连通区域。
graph LR Seg[图像分割] --> Global[binary_threshold: 自动全局] Seg --> Dynamic[dyn_threshold: 局部动态对比] Seg --> Var[var_threshold: 均值标准差] Seg --> Water[watersheds: 分水岭/洼地] Seg --> Grow[regiongrowing: 种子生长]
auto_threshold binary_threshold dyn_threshold regiongrowing_mean

5. 特征提取 (Feature Extraction)

逻辑：对分割后的 Region 或 XLD 进行定量描述。筛选过程通常是：计算特征 -> 设定范围 -> `select_shape`。纹理特征基于共生矩阵，描述灰度空间分布的规律性。
graph LR Feature[特征提取] --> Shape[形状特征: 面积/圆度/矩形度] Feature --> Gray[灰度特征: 均值/标准差/能量] Feature --> Texture[纹理特征: 能量/相关性/反差] Shape --> Select[select_shape] Gray --> SelectG[gray_features] Texture --> Cooc[gen_cooc_matrix]

6. 亚像素边缘与 XLD 轮廓 (Edges & Contours)

逻辑：提取边缘后，XLD 通常是不连续的。需要经过：分割(线/弧) -> 筛选(长度) -> 连接(共线/端点) -> 拟合(最小二乘法) 这一标准流程来获得高精度的几何参数。
graph LR Detect[edges_sub_pix] --> Split[segment_contours_xld] Split --> FilterX[select_contours_xld] FilterX --> Union[union_collinear_contours_xld] Union --> Fit{轮廓拟合} Fit --> FitLine[fit_line_contour_xld] Fit --> FitCircle[fit_circle_contour_xld]
