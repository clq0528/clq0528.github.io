为什么“从右向左”切换 Tab 会失效？

排查核心：上下文丢失 (Trace Context Loss)
sequenceDiagram participant Browser as 浏览器页面 participant App as Java 应用 participant Agent as SW Agent participant OAP as SW 后端 Note over Browser, Agent: 【正常：从左向右点】 Browser->>App: 携带 TraceHeader (ID: 001) App->>Agent: 保持线程上下文 Agent->>OAP: 发送 AWR 数据 (关联 ID: 001) Note over Browser, Agent: 【异常：从右向左点】 Browser->>App: 异步请求/刷新 (无 Header 或 新 ID) App-->>Agent: 线程切换/上下文丢失 Agent--xOAP: 数据断层 (无法关联之前的操作)
技术原因分析： 1. Trace 传递中断： 从右往左点可能触发了页面的重新加载或非受控的异步请求，导致 HTTP Header 中的 `sw8` 追踪头丢失。 2. 异步超时： Oracle 生成 AWR 较慢（类比慢 SQL），如果此时切换 Tab，前端可能直接断开连接，探针捕捉到异常结束，导致数据无法上报。 3. 缓冲区限制： AWR 文本过大，Agent 的 `Log Reporter` 缓冲区是有大小限制的，频繁切换会导致缓冲区溢出。
